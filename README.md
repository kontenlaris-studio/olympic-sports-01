One funny single-line sport the Olympics turned down, for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da).

> Underwater basket weaving: the baskets kept floating away, so after 4 minutes the judges scored the swimmers on their excuses instead.

Run it:

```sh
python3 main.py
```

It prints the line and writes it to `/output/entry.txt`.
